# GLADE — Character Concept Art (Gallery Manifest)

Concept art for the [Bestiary & Rarity Codex](./BESTIARY.md), generated with **Higgsfield**
(`nano_banana_pro`, 2K), reference-chained from a single base "anchor" so every piece reads as
the same species. Art direction: *hand-painted 2D storybook / creature-collector concept art —
soft, cozy, magical, never photoreal.*

> **Note:** the rendered PNGs live in the Higgsfield workspace (this build environment's egress
> policy blocks the image CDN, so they aren't committed here). Each entry lists its **job ID**
> (permanent handle in the workspace) and the exact **prompt**, so any piece can be re-opened,
> re-downloaded, or regenerated. To pull them into the repo, download from Higgsfield into
> `glade/design/characters/` with the filenames below.

(referenced by the sheets below for a consistent body/style).
