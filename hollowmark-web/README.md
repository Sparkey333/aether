# HOLLOWMARK — Greybox Slice (browser / Tauri prototype)

A playable **feel test** of the HOLLOWMARK design in [`../hollowmark/`](../hollowmark/):
third-person movement (double-jump, coyote time, dash), the Splitfang with
three swappable cores, Hollow form with corruption, enemy waves, and a
simplified Vat-Thing boss — all greybox primitives, deliberately PS2-crunchy
(rendered at 35% resolution and upscaled pixelated).

> The real game lives in the Unity project. This exists so you can feel the
> loop on your Mac in under a minute.

## Fastest test (no Rust needed) — browser

```bash
cd hollowmark-web
npm install
npm run dev        # → http://localhost:5173, click to lock the mouse
```

## Build the Mac app + DMG (on your Mac)

DMGs can only be produced **on macOS** — a cloud Linux session cannot emit
one. On your Mac:

```bash
# one-time prerequisites
xcode-select --install                                   # Apple build tools
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh   # Rust

cd hollowmark-web
npm install
npm run icon         # regenerates src-tauri/icons from app-icon.png (if missing)
npm run tauri build
```

The installer lands at
`src-tauri/target/release/bundle/dmg/HOLLOWMARK_0.1.0_aarch64.dmg`
(`_x64.dmg` on Intel Macs), with the raw `.app` next to it under `macos/`.
For a quick iterate-in-a-window loop use `npm run tauri dev` instead.

## Controls

| | |
|---|---|
| WASD + mouse | move / look (click to capture the mouse, Esc to release) |
| Space | jump / double jump |
| Shift | dash |
| LMB | fire · **hold to charge Sunder** · **Q/E** swap core (Maw / Lance / Swarm / Sunder) |
| F | melee (triggers Hollow Lash while transformed) |
| T | Hollow form (needs 50+ meter — kills fill it) |
| R | refill ammo · Esc release mouse |

## What to try

Run the platform gauntlet north of spawn, grab sparks, walk into the arena
(east) to trigger two waves (the second adds ranged spitters), go Hollow
mid-fight, then wake the Vat-Thing in the south-east corner — jump when the
orange ring flares. Aim at an enemy's glowing core; the crosshair flashes
teal on a hit, amber on a kill. Hold LMB on the Sunder core to charge a
chaining arc-plasma orb.

## What's procedural (no asset files)

Everything is generated in code — a deliberate constraint so the whole
prototype is one dependency-light bundle:

- **Textures** (`src/textures.js`) — cracked ground, riveted metal, grime,
  the star-dusted sky dome, and the glowing Riftmaw disc, all drawn to
  `<canvas>` at load and used as `CanvasTexture`s.
- **Audio** (`src/audio.js`) — every SFX is synthesized with the Web Audio
  API (oscillators + filtered noise), composed per event. Resumed on the
  first click. Falls back silently if Web Audio is unavailable.

## Prototype scope notes

- Camera now has collision pull-in and a light hit-shake; enemies are still
  ground-only; the Skiff remains Unity-slice-only. This is a taste, not the
  build target.
- The single-file [`dist-artifact/hollowmark.html`](scripts/build-artifact.mjs)
  build inlines three.js + textures + audio + game into one HTML file with
  no external fetches — `node scripts/build-artifact.mjs`.
- `app-icon.png` is generated by `node scripts/gen-icon.mjs` (zero deps).
